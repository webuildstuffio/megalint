Integration

      

        

          
CLI

          
./megalint.sh --mode skills /path/to/skills
./megalint.sh --json --quiet /path
./megalint.sh --list-rules
./megalint.sh --preset strict /path

        

        

          
MCP Server

          
bun run mcp/server.ts
# or in mcp.json:
{
  "megalint": {
    "command": "bun",
    "args": ["run", "mcp/server.ts"]
  }
}

        

        

          
CI (GitHub Actions)

          
- uses: webuildstuffio/megalint@main
  with:
    path: ./skills
    mode: skills
    preset: balanced
    fail-on-error: true

        

        

          
Web Dashboard

          
bun run serve
# or
bun run web/server.ts --port 7777
